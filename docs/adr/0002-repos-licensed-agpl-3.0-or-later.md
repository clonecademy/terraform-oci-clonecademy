# Modules and the tenancy repo are licensed AGPL-3.0-or-later

Every module, and the tenancy repo, is published under `AGPL-3.0-or-later` with the copyright line `Copyright (C) 2026 Clonecademy`, so anyone may learn from, use and fork them, but no fork can be closed. We accepted the cost: many organisations ban AGPL dependencies outright, so outside adoption will be low, which Apache-2.0 would have avoided. The Terraform Registry places no condition on licences, and the MPL-2.0 `oracle/oci` provider runs as a separate plugin, so nothing technical stands in the way. The tenancy repo only consumes the modules from the Registry, so it could have taken any licence; it takes the same one so the whole family stays under one licence. Relicensing later needs the consent of every contributor, which is why this is recorded.
