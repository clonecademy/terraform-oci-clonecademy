# Modules are licensed AGPL-3.0-or-later

Every module is published under `AGPL-3.0-or-later`, so anyone may learn from, use and fork the modules, but no fork can be closed. We accepted the cost: many organisations ban AGPL dependencies outright, so outside adoption will be low, which Apache-2.0 would have avoided. The Terraform Registry places no condition on licences, and the MPL-2.0 `oracle/oci` provider runs as a separate plugin, so nothing technical stands in the way. Relicensing later needs the consent of every contributor, which is why this is recorded.
